# Roadmap & Known Limitations

## Current Prototype State

- Browser-based H5 game with PWA metadata and service-worker caching.
- Shop progression and manager collection systems.
- Eighteen-manager roster structure and six-member team model.
- Economy simulation and automated regression assets.
- Provider-neutral advertising and cloud-save contracts.

## Remaining Work

- Complete English localization of all in-game strings and asset metadata.
- Perform real-browser and physical-device visual QA.
- Review generated-art edge quality and consistency in the live UI.
- Finalize candidate economy values and later-region unlock conditions.
- Integrate and test a real rewarded-ad provider.
- Implement and validate cloud-save infrastructure.
- Decide whether a native wrapper and store distribution are required.
- Add a reproducible build/release workflow and CI pipeline.

## Release Gate

A public production release should not be declared until localization, device QA, economy sign-off, platform integration, privacy/compliance review, and save migration testing are complete.

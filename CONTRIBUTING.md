# Contributing

Thanks for your interest in the project. This repository is primarily a portfolio prototype.

## Before submitting changes

1. Explain the gameplay or technical problem being addressed.
2. Preserve stable manager IDs and save-schema compatibility unless a migration is included.
3. Keep candidate balance values separate from approved runtime values.
4. Update the relevant documentation and research notes.
5. Run the most relevant regression checks and report any checks that could not be run.
6. Do not commit API keys, SDK credentials, private signing material, or personal data.

## Art and AI-generated assets

New assets should follow the established visual direction and include a clear mapping to the runtime resource that uses them. AI-generated output must be reviewed before integration.
